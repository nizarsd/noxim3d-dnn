\section{Background and Related Work}
\label{sec:related}
Wafer-scale integration shows what collapsing memory into compute costs at the largest scale yet built: Cerebras' WSE-3 holds 44 GB on-wafer at 21 PB/s while provisioning 214 Pb/s of on-chip fabric — as reported, more aggregate bandwidth in the network than in the memory it serves \cite{CerebrasWSE2025}. Crossbar-based accelerators make the same collapse at tile granularity, so the interconnect rather than memory becomes the resource that mapping must be designed against \cite{CerebrasWSE2025}.
